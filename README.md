# АвтоАтелье

Тестовый сайт автомастерской: кабинет клиента, управление заказами сотрудником, фотоотчёт, приёмка, чат, запись на свободное время, цены и вымышленные отзывы.

[Открыть демоверсию](https://autoatelier-demo.heartymelon64.chatgpt.site) — доступ к сайту пока ограничен владельцем. Доступ к сайту настраивается отдельно от видимости репозитория с исходным кодом.

## Технологии и файлы

HTML, CSS и JavaScript без фреймворков и обязательных внешних зависимостей.

- `dist/index.html` — структура страницы.
- `dist/style.css` — оформление и адаптация для телефона.
- `dist/app.js` — кабинеты клиента и сотрудника, запись, чат и тестовый вход.
- `dist/assets/` — демонстрационные фотографии.

## Просмотр

Для просмотра откройте опубликованный сайт или запустите статический сервер для папки dist. Сборка и установка npm-пакетов не нужны.

## Ограничения демоверсии

Демо хранит данные в localStorage браузера, синхронизирует вкладки одного браузера, но не разные устройства. Переключатель «Я сотрудник» демонстрирует работу мастера без защищённой авторизации. Вход по телефону принимает тестовый код 1234, SMS не отправляет и показывает общий демонстрационный заказ. Уведомления отображаются только на сайте. Чат не отправляет сообщения реальным сотрудникам. Запись исключает пересечение времени с учётом длительности услуги в рамках текущего браузера.

Для реальной мастерской потребуются серверная база, разделение прав и заказов по клиентам, провайдер SMS и уведомления. Не использовать реальные персональные данные в демо.

Демонстрационные фотографии — Unsplash, не подтверждение выполнения ремонта. Сотрудник может загрузить собственные JPG/PNG/WebP (до 8 фото на заказ); они уменьшаются и сохраняются в браузере.
